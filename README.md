# cpsc-6150-net-ninja
Changes made for the [Flutter Beginners Tutorial](https://github.com/iamshaunjp/flutter-beginners-tutorial) and [The Net Ninja YouTube playlist](https://www.youtube.com/playlist?list=PL4cUxeGkcC9jLYyp2Aoh6hcWuxFDX6PBJ) for the CPSC 6150 class.

## How to use these files
Each CPSC 6150 assignment in the course has its own branch in this repository. To see the code for that assignment, choose the appropriate branch. For example, to see the code for assignment `Net Ninja Quote Lab - Part 1`, checkout the `assignment-quote-lab-part-1` branch.

**Important**: If you are cloning the repo to your desktop, you will need to perform a `packages get` / `pub get` to install any dependencies that the project may have at that point in the course.
