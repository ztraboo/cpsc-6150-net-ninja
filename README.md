# cpsc-6150-net-ninja
Changes made for the https://github.com/iamshaunjp/flutter-beginners-tutorial tutorial videos `The Net Ninja` YouTube channel for the CPSC 6150 class.

## How to use these files
Each CPSC 6150 assignment in the courses has it's own branch in this repository. To see the code for that assignment, choose the appropriate branch. E.g. to see the code for assignment `Net Ninja Quote Lab - Part 1`, checkout the assignment-quote-lab-part-1.

**important** - if you are cloning the repo to your desktop, you will need to perform a packages get / pub get to install any dependencies that the project may have at that point of the course.
